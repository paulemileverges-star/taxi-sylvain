Supprimer mon compte Taxi Sylvain

Cette page vous permet de supprimer vous-même votre compte, sans installer l'application. Prenez une minute pour lire ce qui suit : la suppression ne s'annule pas.

Ce qui est supprimé

  • Votre compte et votre mot de passe.
  • Vos renseignements personnels : nom, courriel, téléphone, adresse, photos, notes internes.
  • Les messages que vous avez envoyés.
  • Vos notations.
  • Votre cédule et les groupes que vous avez créés.
  • Les notifications envoyées à votre téléphone.

Ce qui est conservé

Vos courses passées restent dans les registres de Taxi Sylvain, parce que la comptabilité l'exige (redevance de 10 %). Elles ne sont plus reliées à votre compte : votre nom et vos coordonnées en sont retirés.

C'est définitif

La suppression est immédiate et définitive. Il n'y a aucun moyen de récupérer votre compte, votre historique ou vos messages par la suite. Pour revenir, il faudra créer un nouveau compte.

Quand la suppression est refusée

  • Vous avez une course en cours. Terminez ou annulez la course, puis revenez ici. Ça vaut autant pour le client que pour le chauffeur.
  • Vous êtes le compte Dispatch. Ce compte fait fonctionner l'entreprise : il ne se supprime pas depuis cette page.
  • Vous êtes un compte administrateur. Ces comptes sont gérés par Taxi Sylvain. Demandez au Dispatch de le faire pour vous.

Supprimer mon compte

Votre mot de passe actuel est exigé, pour être certain que c'est bien vous.

Deux autres façons de faire

Vous pouvez aussi supprimer votre compte directement dans l'application, menu Supprimer mon compte.
